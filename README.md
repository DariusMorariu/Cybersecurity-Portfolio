## Current Project

### Budget Cybersecurity Homelab

I am designing and building a compact 10-inch homelab around a refurbished
Fujitsu ESPRIMO Q556/2. The project includes hardware validation, a custom
3D-printed rack mount, managed networking, an ESP32 status display and a
planned Proxmox virtualization environment.
